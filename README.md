# Scape-From-Goth-Girl
Scape From Goth Girl - Colored hair, Dark intentions (SFGG) é um Projeto de um jogo 2d desenvolvido em java para estudos. o jogo tem um tema comico e leve e o objetivo é fazer com que nosso personagem principal fuja de mulheres góticas, cabelos coloridos etc, conforme as fases vão passando
